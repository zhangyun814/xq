# 翻倍信号筛选

从知识星球语料里提炼「翻倍」这类说法的买入信号，用历史行情验证它到底赚不赚钱，再把结论做成一个点按钮就能跑的筛选台。

核心结论：**「翻倍」这个词必须拆开看**。语料里它 54% 指业绩翻倍、24% 才指目标价，两者的股价含义几乎相反。只有目标价那一层站得住，且窗口在 20 个交易日，不是 5 天。

---

## 结论摘要

| 口径 | N | T+20 超额均值 | 中位 | 胜率 | t 值 |
|---|---|---|---|---|---|
| **目标价翻倍** | 46 | **+11.28%** | +3.53% | 54.3% | **2.67** |
| 业绩翻倍 | 91 | −1.44% | −1.96% | 41.8% | — |
| 模糊 | 32 | +6.43% | +7.61% | 59.4% | — |

**买入**：信号次日开盘买入，不挂回调单、不等均线。11 种时点里次日买入是唯一全胜解（100% 成交、+12.14%）。等 −3% 回调的条件收益 +12.52% 看着更高，但只买到 51.1% 的单子，整体掉到 +6.40%；等 −8% 的条件收益是 **−3.18%**——愿意深跌才买的，买到的都是坏消息。

**卖出**：不设止损。21 种出场规则里 9 个带价格触发的全部更差。入场后最大浮亏中位就是 −10%，8% 止损会打掉 57.8% 的仓位，而收益高度依赖右尾（最大浮盈均值 +31.7%）。机械出场就「止盈 +10% 或持满 20 个交易日，先到先出」。

## 快速开始

```bash
# 1. 首次：重建股票名录（依赖网络）
python3 build_universe.py

# 2. 全量同步语料 + 抓行情 + 跑回测（几分钟）
python3 run_all.py

# 3. 筛选：近 5 天信号 ∩ 近 90 天活跃池
python3 active_signals.py

# 4. 起 Web 界面
python3 webapp.py          # → http://localhost:8000
# 或容器
docker compose up -d       # → http://localhost:8000
```

### 命令行参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--mode target` | ✅ | 只保留「目标价」层（推荐） |
| `--mode all` | | 含业绩、称谓、模糊 |
| `--win5 N` | 5 | 信号帖的时间窗口（天） |
| `--pool N` | 90 | 活跃池范围（天） |

### 页面

- `http://localhost:8000/` — 点「重新筛选」重算
- `http://localhost:8000/?run=target,5,90` — 打开即跑，可存书签
- `POST /api/screen-sync` — 一次请求拿结果，方便脚本调用

## 依赖

**全部是 Python 标准库**，无第三方包。外部只依赖两个东西：

1. `zsxq-cli` —— 抓知识星球帖子。需要在本机登录过，凭证存在系统钥匙串里。
2. `curl` —— 拉行情（腾讯财经、新浪财经）。

**抓帖必须在有凭证的机器上跑。** Linux 容器解不开 macOS 钥匙串，所以容器里只能做重算，不能抓新帖——这是设计上的边界，不是 bug。

## 语义消歧怎么做的

同一句「翻倍」可以是三种意思，必须先分清：

```
"净利同比翻倍"        → 业绩（已发生，通常早被 price in）
"至少翻倍以上空间"    → 目标价（卖方在给未来位置）
"今年第三只翻倍股"    → 称谓（复盘，无预测含义）
"翻倍增长可期"        → 模糊
```

判定方法：看信号词前后 ±18/22 字内，**股价类词**（空间/股价/目标价/市值/弹性/涨幅/上行/赔率/上看/至少）和**业绩类词**（净利/扣非/归母/营收/收入/毛利/同比/环比/增长/指引/出货/订单…）谁离得更近。

另外有一条**过去时过滤**：窗口里出现「已、接近、年内、累计、涨幅达」这类词，且没有「有望、目标、空间、将、预计」时，判为业绩。这条规则是为了修掉「药明康德年内股价已接近翻倍」被误判成目标价——那句话在复述涨幅，不是给目标价。

## 踩过的坑

**开/收必须同源。** 首版混用新浪不复权收盘 + 腾讯前复权开盘，算出 −31.7% 的隔夜缺口和 +42.7% 的日内涨幅，数字荒谬到一眼假（688623 前收 93.25、开 63.65、收 90.83）。改成两个价格都取腾讯前复权后，缺口回到 +2.49%、中位 +0.13%，合理。

**「等回调」是幸存者偏差。** 只看成交样本，等 −3% 回调的收益比直接买还高。必须同时报「条件收益」（只算买到的）和「整体收益」（买不到记 0），才能看出真相。

**发帖时间决定可行性。** 60%+ 的帖子发在 21–23 点，当日收盘买入根本不可能，最早的下手时点是次日开盘。

**语义规则改一处，全表数字都要重跑。** 加过去时过滤后，目标价口径从 47 掉到 46，t 值从 2.62 变 2.67，业绩口径从 82 涨到 91。改完 `semantics.py` 必须重跑 `event_study` → `exit_rules` → `entry_rules` → `report.html`，不能只改一处。

## 口径边界

- 样本期 2025-08 ~ 2026-10，**单边偏强市**，熊市未验证
- 未计交易成本、滑点、涨跌停约束
- t 值未做多重比较校正（11 个分组同时检验，Bonferroni 阈值约 2.8），**属方向性参考，不是可以下重手的依据**
- N=46 不大，个别极端值对均值影响明显，中位数更可靠

这个项目能回答「这类说法历史上赚不赚钱」，不能回答「明天该买什么」。
